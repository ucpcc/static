# 아카이브 메일 양식

직접 Pull Request를 열기 어렵다면 아래 형식에 맞춰 `archive@ucpc.me`로 보내 주시기 바랍니다.

## 작성 양식

```text
[단체]
- 이름:
- 디렉터리 이름(org slug):

[담당자]
- 이메일:

[단체 라이선스 / 저작권 고지]
- 첨부 여부:
- 참고사항:

※ 새 단체를 추가하는 경우에는 단체 정책에 맞는 라이선스 또는 저작권 고지 파일을 반드시 함께 보내 주시기 바랍니다.

[대회 목록]

[대회 1]
- 이름:
- 디렉터리 이름(contest slug):
- 연도:
- 첨부 자료:
  - 문제:
  - 해설:
  - 테스트데이터 외부 링크:
  - 스코어보드:
  - 기타:
- 참고사항:

[대회 2]
- 이름:
- 디렉터리 이름(contest slug):
- 연도:
- 첨부 자료:
  - 문제:
  - 해설:
  - 테스트데이터 외부 링크:
  - 스코어보드:
  - 기타:
- 참고사항:

[권리 및 책임 관련 확인]
- 본 자료를 아카이브에 업로드할 수 있는 권한이 있음을 확인했습니다.
- 저작권, 라이선스, 기타 권리 관계상 문제가 없는지 확인했습니다.
- 제3자 소프트웨어나 자료가 포함된 경우 관련 고지를 함께 제공합니다.
```

## 작성 안내

- `org slug`는 단체 디렉터리 이름으로 사용합니다.
  예: `archive/{org}/`
- `contest slug`는 대회 디렉터리 이름으로 사용합니다.
  예: `archive/{org}/{contest}/`
- 여러 대회를 한 번에 보내는 경우에는 `[대회 1]`, `[대회 2]` 항목을 복사해서 이어서 작성합니다.
- 테스트데이터는 용량 문제 때문에 이 저장소에 직접 올리지 않고, 가능하면 GitHub Releases, Google Drive 등 외부 저장소 링크로 보내 주시기 바랍니다.
- `org slug`와 `contest slug`는 영어 소문자와 `-`만 사용합니다.
- 공백, 대문자, 한글, 특수문자 대신 `-`로 정리해 주시기 바랍니다.
- 단체명은 너무 짧은 이름보다, 소속을 함께 드러내는 이름을 권장합니다.
  예를 들어 `run` 보다는 `kaist-run` 같은 형태를 권장합니다.

예시:

- `ucpc`
- `kaist-run`
- `sogang-icpc`
- `ucpc-2025`
- `kaist-run-2024-spring`
