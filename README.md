# static

`static.ucpc.me`에 배포되는 정적 자료 저장소입니다.

전국 대학생 프로그래밍 대회 동아리의 각종 정적 자료와 산하 동아리 개최 대회 파일 아카이브를 함께 관리합니다.

자세한 아카이브 구조와 기여 방법은 `./archive/` 아래 문서를 참고합니다.

## 로컬 빌드

로컬에서 GitHub Pages와 비슷하게 확인하려면 저장소 루트에서 아래 명령을 실행합니다.

```bash
jekyll build
jekyll serve
```

- `jekyll build` : 정적 사이트를 `_site/`에 생성합니다.
- `jekyll serve` : 로컬 서버를 띄워 브라우저에서 확인할 수 있게 합니다.

기본적으로 `http://127.0.0.1:4000`에서 확인할 수 있습니다.

## 권리 및 이용

본 저장소의 자료는 전국 대학생 프로그래밍 대회 동아리 연합 및 각 자료 제공자의 정책에 따라 관리합니다.

`archive/` 아래 자료는 각 단체 또는 하위 디렉터리에 별도로 적힌 라이선스 및 저작권 고지가 있으면 그 내용이 우선합니다.

기여자가 제출한 자료의 저작권, 라이선스, 기타 권리관계에 대한 1차적 책임은 해당 자료를 제출한 기여자에게 있습니다.

전국 대학생 프로그래밍 대회 동아리 연합은 제출된 자료의 권리관계를 사전에 독립적으로 검증하거나 보증하지 않습니다.

권리자 또는 이해관계자가 저작권, 라이선스, 기타 권리 침해를 신고하는 경우, 전국 대학생 프로그래밍 대회 동아리 연합은 관련 내용을 검토한 뒤 필요한 범위에서 자료를 수정, 비공개 처리, 또는 삭제할 수 있습니다.

권리침해 신고 및 문의: `archive@ucpc.me`
