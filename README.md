# static

`static.ucpc.me`에 배포되는 정적 자료 저장소입니다.

전국 대학생 프로그래밍 대회 동아리의 각종 정적 자료와 산하 동아리 개최 대회 파일 아카이브를 함께 관리합니다.

자세한 아카이브 구조와 기여 방법은 `./archive/` 아래 문서를 참고합니다.

## 로컬 빌드

로컬에서 GitHub Pages와 비슷하게 확인하려면 저장소 루트에서 아래 명령을 실행합니다.

```bash
jekyll build
jekyll serve
```

- `jekyll build` : 정적 사이트를 `_site/`에 생성합니다.
- `jekyll serve` : 로컬 서버를 띄워 브라우저에서 확인할 수 있게 합니다.

기본적으로 `http://127.0.0.1:4000`에서 확인할 수 있습니다.
